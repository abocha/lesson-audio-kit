### 🎯 Цели проекта (SMART-формулировка)

| # | Цель                                                                          | KPI / метрика                        | Срок MVP |
| - | ----------------------------------------------------------------------------- | ------------------------------------ | -------- |
| 1 | Сократить время на подготовку **1 listening-активности** до 3 мин             | ⟵ self-timer baseline 15 мин → 3 мин | 4 недели |
| 2 | Уложиться в **≤ \$10/месяц** на TTS для 30 уроков                             | затраты < \$0.33 / урок              | 4 недели |
| 3 | Поддерживать **3 TTS-движка** (OpenAI, ElevenLabs, Fal) с авто-маршрутизацией | выбор движка ≤ 300 мс                | 6 недель |
| 4 | Иметь **99 % кэш-хит** при повторном редактировании диалога                   | повторная озвучка ≤ 1 реплики        | 6 недель |

---

### 🔨 Задачи MVP (малый scope)

1. **Core-библиотека**

   * `generate_text(prompt, model_id)` (OpenAI / Fal)
   * `synthesize_audio(script, tts_id)` с фразовым кэшем
2. **Streamlit-UI**

   * Поле для prompt → кнопка **Generate text**
   * Предпросмотр → **Generate audio** + плеер / download
   * Показ «Estimated cost» и выбор качества (basic / premium)
3. **API-слой** для старого Gradio‐space (`/api/tts`)
4. **Логи & расход** — SQLite + simple dashboard в Streamlit
5. **Документация** — README + demo-видео

> 💡 **Что НЕ входит в MVP:** уровни CEFR, личные цели ученика, автоматическая грамматика / упражнения.

### 🛣️ Дорожка расширения

| Этап     | Добавляем                                                             | Когда включаем                                            |
| -------- | --------------------------------------------------------------------- | --------------------------------------------------------- |
| **v1.1** | Метаданные (speaker tags, эмоции-теги) в исходном тексте              | после стабилизации кэша                                   |
| **v1.2** | Lesson Builder: шаблоны lead-in, tasks, HW на основе уровня           | как только нужен полный урок минимум двум ученикам        |
| **v2**   | Umbrella-Hub: drag-and-drop внешнего текста, PDF-экспорт, Notion sync | когда появится 5+ постоянных преподавателей-пользователей |

---

### 🤔 Почему начинаем с малого scope

* **Надёжность** — один короткий флоу → легче отлаживать.
* **Предсказуемое качество** — меньше вариативных параметров prompt-а.
* **Быстрый ROI** — сразу экономишь время на каждую listening-часть, не дожидаясь «идеального» урокогенератора.
* **Гибкость** — core-модуль остаётся тем же, а Lesson Builder просто вызывает его с большим количеством контекста.

### ✅ Итого

1. **MVP-scope**: генерируем текст *диалога / монолога* + озвучка с авто-кешем, три TTS-движка, прозрачная цена.
